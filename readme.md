# MyCV - Single Page HTML CV

This project is a single-page CV built using HTML, inspired by the [roadmap.sh single-page CV guide](https://roadmap.sh/projects/single-page-cv). Follow the instructions below to view and customize the CV.

## Prerequisites
- A web browser (e.g., Google Chrome, Firefox, Edge, etc.)
- Basic knowledge of HTML (optional, for customization)

## How to View the CV

1. **Locate the `index.html` File**  
  Ensure the `index.html` file is in the project directory. Example:  
  ```
  /home/fayad/MyCV/
  ```

2. **Open the File**  
  - **Option 1**: Double-click the `index.html` file to open it in your default web browser.  
  - **Option 2**: Right-click the file, select "Open With," and choose your preferred browser.  
  - **Option 3**: Open it via the terminal:  
    ```
    cd /home/fayad/MyCV/
    google-chrome index.html
    ```
    Replace `google-chrome` with your browser's command if necessary.

3. **View the CV**  
  The CV will be displayed in your browser as a single-page document.

## How to Customize the CV

1. **Edit the HTML File**  
  Open the `index.html` file in a text editor or IDE of your choice (e.g., VS Code, Sublime Text, Notepad++).  

2. **Modify the Content**  
  Update the sections (e.g., name, contact information, skills, experience) to reflect your personal details.  

3. **Save Your Changes**  
  Save the file and refresh the browser to see the updated CV.

## Additional Resources
- [roadmap.sh single-page CV guide](https://roadmap.sh/projects/single-page-cv)
- [HTML Reference](https://developer.mozilla.org/en-US/docs/Web/HTML)

Enjoy building your CV!
# How to Run the `index.html` File

Follow these steps to open and view the `index.html` file in your browser:

## Prerequisites
- A web browser (e.g., Google Chrome, Firefox, Edge, etc.)
- The `index.html` file located in your project directory

## Steps
  
> **Note**: Ensure that the `index.html` file is not moved or renamed, as this may cause issues when trying to open it. If you encounter any problems, verify that the file exists in the specified directory.

    - Example: `/home/fayad/MyCV/`

2. Open the file:
    - **Option 1**: Double-click the `index.html` file. It should automatically open in your default web browser.
    - **Option 2**: Right-click the file, select "Open With," and choose your preferred web browser.

3. Alternatively, you can open it via the terminal:
    - Use the `cd` command to navigate to the directory:
      ```
      cd /home/fayad/MyCV/
      ```
    - Open the file using a browser command (example for Google Chrome):
      ```
      google-chrome index.html
      ```
      Replace `google-chrome` with your browser's command if necessary.

4. The `index.html` file should now be displayed in your browser.

Enjoy!
